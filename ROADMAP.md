# Roadmap

## v1.0

Single-site WordPress clone testing, local/archive/Agent sources, safe local
packages, functional/visual/accessibility/runtime/network/performance rules,
dashboard, reports, demo, CI, and reproducible packaging.

## Post-v1 candidates

- Explicit WordPress multisite support
- Richer third-party rule/adapter discovery and signed package policy
- Optional Firefox/WebKit default matrices
- More hosting-specific import helpers
- Additional local dummy payment/order workflows
- Stronger OS-specific credential-store integration

Hosted SaaS, production updates, real payments/email, automatic premium-package
acquisition, non-WordPress CMS support, Kubernetes, distributed workers, AI
autofixes, public telemetry, and mobile applications remain non-goals unless the
governance process explicitly revisits them.
