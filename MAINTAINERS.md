# Maintainers

Owner-specific identities are intentionally not inferred from local Git config.
Before public release replace:

- `REPLACE_BEFORE_RELEASE_GITHUB_OWNER`
- `REPLACE_BEFORE_RELEASE_SECURITY_CONTACT`
- repository and package URLs using `REPLACE_BEFORE_RELEASE.invalid`

Initial release authority: `REPLACE_BEFORE_RELEASE_GITHUB_OWNER`.

See [GOVERNANCE.md](GOVERNANCE.md) for appointment, review, inactivity, and
security-response responsibilities.
