# Support

Use documentation and troubleshooting first. Public Discussions may be used for
sanitized usage questions after the repository URL is configured. Bugs belong in
the bug template with versions and reproduction. Never attach a production
export, token, credential, customer data, or unredacted log. Security issues use
the private procedure in [SECURITY.md](SECURITY.md).

Community support is best effort; no SLA or warranty is provided.
