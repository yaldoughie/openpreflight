# Privacy

OpenPreflight collects no telemetry, analytics, identifiers, or usage metrics.
It uses no CDN, remote font, automatic report upload, public link, or default
sharing. Site data and artifacts stay in the configured local directory.

Production clones can contain customer records, unpublished content, licensed
code, and secrets. Known WordPress/WooCommerce sessions, personal fields,
payment tokens, API option patterns, and integration endpoints are sanitized,
but arbitrary plugins can store data unpredictably. Never claim an export is
fully anonymized. Use minimal upload mode, additional trusted hooks/SQL where
needed, access controls, encryption at rest for the host, and prompt retention.
Comply with applicable law, contracts, and data-processing obligations.
