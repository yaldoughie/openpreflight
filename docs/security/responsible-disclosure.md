# Responsible disclosure

Follow [the repository security policy](../../SECURITY.md). Never open a public
vulnerability issue or include production data. Use
[GitHub Private Vulnerability Reporting](https://github.com/yaldoughie/openpreflight/security/advisories/new).
Reports receive confidential triage, coordinated remediation/disclosure, and
requested credit. Good-faith testing must minimize data access and avoid
persistence, disruption, social engineering, or third-party systems.
