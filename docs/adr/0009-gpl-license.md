# ADR 0009: GPL-2.0-or-later

Status: Accepted

## Context

OpenPreflight integrates deeply with GPL WordPress and should remain freely modifiable.

## Decision

License original project code GPL-2.0-or-later and review dependency compatibility.

## Consequences

Distributed derivatives must honor GPL terms; permissive dependencies remain compatible.

## Alternatives considered

MIT/Apache-only licensing did not match the WordPress integration objective.
