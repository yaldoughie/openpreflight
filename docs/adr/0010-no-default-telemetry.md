# ADR 0010: No default telemetry

Status: Accepted

## Context

Runs process sensitive cloned sites and self-hosting is a core promise.

## Decision

Collect no telemetry or analytics, load no remote frontend assets, and never upload/share reports automatically.

## Consequences

Privacy and offline operation improve; maintainers rely on voluntary sanitized issue reports.

## Alternatives considered

Opt-out metrics and third-party analytics were rejected. Any future opt-in proposal requires a new ADR.
