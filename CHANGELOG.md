# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and Semantic Versioning.

## [1.0.0] - 2026-07-18

### Added

- Self-hosted CLI, Fastify API, SQLite worker queue, and accessible React dashboard.
- Local path, safe archive, and scoped WordPress Agent source adapters.
- Disposable Docker WordPress environments with sanitization and restricted egress.
- Versioned journey language, Playwright runner, WordPress/WooCommerce library, and fixtures.
- Runtime, network, visual, accessibility, and performance comparison rules.
- Offline HTML, JSON, JUnit, and SARIF reports with centralized redaction.
- WordPress Agent token, diagnostics, inventory, asynchronous export, and cleanup APIs.
- CI, release packaging, checksums, SBOM, demo, governance, and security documentation.
